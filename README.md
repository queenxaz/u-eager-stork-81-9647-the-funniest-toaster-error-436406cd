One line: the funniest error message a kitchen toaster could show its owner.

`main.py` writes that single line to `/output/entry.txt` — no network, no
randomness, fully deterministic. The line is 72 characters, inside the
120-character limit:

> Error 451: This bread is unavailable for legal reasons. It has a lawyer.

The joke borrows a real error code — HTTP 451, "unavailable for legal
reasons" — and lets the toaster wear it deadpan: the bread hasn't burnt,
it has lawyered up.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
